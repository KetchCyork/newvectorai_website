A FEW THINGS TO KNOW

Before you join.

When can I use Kolloq?

Kolloq is pre-launch. Join the waitlist to hear about availability as launch plans develop.

Do I need my own AI provider account?

Kolloq supports your own provider accounts and API keys. Ollama can run local models without an API key. Provider charges may apply separately.

Is the Advisory Council the same as delegation?

They are different ways of working. Delegation assigns subtasks to specialist agents. The Advisory Council brings multiple agents into a discussion that a moderator synthesizes.

Where are credentials stored?

The repository describes OS keychain storage for the desktop app and browser storage for the browser app. Storage and security expectations depend on the environment you choose.
